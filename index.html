A dbt mart that rolls each customer's full purchase history into one row: lifetime value, order count and first and last order dates. Lightly trimmed for length.

-- Mart: one row per customer, powering "top customers" reporting.
with customer_sales as (
    select * from {{ ref('customer_sales') }}
)

select
    user_id,
    full_name,
    state,
    count(transaction_id)          as transaction_count,
    sum(quantity)                  as total_items_purchased,
    round(sum(total_amount), 2)    as lifetime_value,
    round(avg(total_amount), 2)    as avg_order_value,
    min(order_date)                as first_order_date,
    max(order_date)                as last_order_date
from customer_sales
group by 1, 2, 3
order by lifetime_value desc

From my Financial Dashboard. One measure drives the whole income statement: detail rows show operating income, and subtotal rows show a running total down the P&L. A second measure adds month-over-month change. Lightly trimmed for length.

P&L Amount =
VAR vRT =
    CALCULATE (
        [Operating Income],
        FILTER (
            ALL ( dAccountHeader ),
            dAccountHeader[HeaderID] <= MAX ( dAccountHeader[HeaderID] )
        )
    )
VAR vSubTotal = MAX ( dAccountHeader[Subtotal] )
VAR vSubHeaderScope = ISINSCOPE ( dAccount[Subheader Account] )
RETURN
    SWITCH (
        vSubTotal,
        0, [Operating Income],
        1, IF ( vSubHeaderScope, BLANK (), vRT ),
        BLANK ()
    )

MoM Change % =
VAR vPrevMonth =
    CALCULATE ( [P&L Amount], DATEADD ( 'Date'[Date], -1, MONTH ) )
RETURN
    DIVIDE ( [P&L Amount] - vPrevMonth, ABS ( vPrevMonth ) )
