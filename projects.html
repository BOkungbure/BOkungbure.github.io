Name Generator → Sales Analytics Pipeline ↗

An end-to-end analytics engineering pipeline that generates synthetic customers and sales every day, appends them to a cloud Postgres database, and builds tested dbt models ready for reporting.

Python/Faker ──► batch CSVs ──► Python loader ──► Neon raw schema │ dbt sources + product seed │ staging views → marts
  • Daily automation: Windows Task Scheduler generates 1,000 customers and 5,000 transactions, loads them and runs dbt build, with logging.
  • Safe, retryable loads: batches load in a single transaction with uniqueness and foreign key checks, and re-running a day skips instead of duplicating.
  • dbt modelling: staging views, customer and product sales marts, YAML docs and tests.
  • History tracking: dbt snapshots record changes to product name, category and price over time.
  • Good security practice: credentials come from environment variables and are never committed.
